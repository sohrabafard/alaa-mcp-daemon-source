# Support

Start with the [product README](./alaa-mcp-daemon/README.md), [configuration guide](./alaa-mcp-daemon/docs/configuration.md), [Windows lifecycle guide](./alaa-mcp-daemon/docs/windows-lifecycle.md), and [validation guide](./alaa-mcp-daemon/docs/validation.md). Together they cover configuration, adding services, lifecycle commands, logs, and the native validation gate.

## Choose the right channel

- For configuration, lifecycle, logging, or validation questions, consult the product documentation first and open an issue only with sanitized details.
- For a reproducible, non-security defect, use the bug-report template.
- For a focused workflow improvement, use the feature-request template.
- For contribution guidance, read [CONTRIBUTING.md](./CONTRIBUTING.md).

For a reproducible defect, include the daemon version, Windows version, sanitized configuration shape, command, expected result, observed state, and relevant redacted logs. State any validation already run, including whether the Windows gate or optional Task Scheduler integration check was deliberately not run.

Do not report vulnerabilities publicly. Follow [SECURITY.md](./alaa-mcp-daemon/SECURITY.md) instead.
