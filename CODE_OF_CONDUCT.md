# Code of Conduct

We want a respectful, technically rigorous community. This Code of Conduct applies to project discussions, issues, pull requests, and other interactions connected to the project. Treat contributors, users, and maintainers with patience; discuss ideas and evidence rather than people; and welcome good-faith questions from newcomers.

Harassment, discrimination, threats, sexualized language or imagery, doxxing, and repeated bad-faith disruption are not acceptable. Respect privacy: do not publish credentials, private paths, personal data, or unpublished security details.

## Reporting

If conduct needs attention, report it privately to the maintainers through an available project channel and include only the context needed to investigate. Do not post sensitive details publicly. If no private reporting channel is published, request reporting instructions publicly without disclosing the incident details.

## Enforcement

Maintainers may clarify expectations, remove content, or restrict participation to protect the community. Retaliation against a reporter is not acceptable. Decisions are made from the available context and may be revisited when material new information is provided.
